# TIRUMANISETTY DEVIR MAHI — Portfolio

Responsive React + Vite portfolio for placements and software/cloud-native opportunities.

## Run locally

Install Node.js LTS, then from this folder:

```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite.

## Production build

```bash
npm run build
```

## Deploy

Import the project into Vercel and use `npm run build` with output directory `dist`.

The uploaded resume is included as `public/resume.pdf`, so the Resume button works.
